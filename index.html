PopCraft CLI Command line

Edit .popcraft files without opening the app, call the REST API, and publish to the marketplace. Good for CI and batch jobs.

brew install getpopcraft/popcraft/popcraft
npm i -g @popcraft/cli

Plugin SDK Extend the editor

The popcraft API and types for plugins, widgets, themes, brushes, shaders and templates, with one working example of each.

Foldable Sim Testing

Test any web app's responsive and foldable layouts in your browser: iPhone, iPad, MacBook, and the iPhone Duo closed, half open and open.

  • Paste a URL; switch device, posture and rotation
  • Your app gets the hinge and crease as CSS attributes and variables
  • Includes a Tailwind example with fold variants
